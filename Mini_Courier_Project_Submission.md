## 3. Objective
The objective of this project is to build a simple courier management system that allows users to create orders, update their delivery status, and calculate total revenue. The application provides a practical demonstration of basic Python programming, data handling, and testing.

## 4. Problem Statement
A courier service needs a simple system to manage package delivery requests efficiently. This includes storing order details, tracking the current status of each package, and generating a revenue summary for all orders.

## 5. Features Implemented
- Create new courier orders
- Store sender, recipient, origin, destination, weight, and priority details
- Track order status: Pending, Picked Up, In Transit, Delivered
- Validate invalid status values
- Display order summaries and revenue totals
- Support interactive menu-based user input
- Include automated unit tests for validation
